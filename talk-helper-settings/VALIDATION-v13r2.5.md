目标微信：4.1.13.65 x64。只在已选择聊天的对方普通文字下方显示卡片；原生消息及其他类型内容由微信继续处理。

- 后台 51 项测试与分析链 114 项测试通过。新增覆盖：候选问题的两项权重、对话用途权重校验、紧张度与首个动作的紧凑展示、停止联系时不编造数字、时间标题、分析完成后的行高切换。

- 新原生 DLL 编译成功；隔离自检通过，含高卡片在原消息下方的跟随、聊天区顶部和底部裁剪、高 DPI 缩放。灰色卡片参考渲染也已人工检查。
- 打包版后台 `--self-test` 退出码为 0。

## 现场状态

本机微信完全退出后，新 DLL 与后台已部署，安装文件 SHA-256 与构建产物一致，原有设置和已选择聊天名单保留。重新登录微信 4.1.13.65 并打开已启用联系人后，现场确认两条对方普通文字各有独立灰色卡片；分析完成的卡片自动加高原消息行，标题、两项权重、对话用途、紧张度与当前动作均显示，原微信消息和顶部按钮仍可见。状态记录显示新版后台、无 OCR、原生消息包与行高调整均已接受，2 条建议生成成功。

现场点击“详情”后，完整发送时间、分析说明、行动、候选回复和注意事项正常显示；收起后回到原卡片。把卡片滚出视野再滚回，卡片仍贴在对应消息下方，原生保留数为 4，成功建议数为 2，滚动期间没有新增成功请求。原生隔离测试另覆盖顶部和底部裁剪。

现场还看到两条较早消息显示“DeepSeek 生成失败；请稍后重试”。它们保留对应灰色卡片，但没有模型判断和百分比；目前未查明这些请求的具体失败原因，不能把该场景记作建议生成成功。

## 解释边界

卡片百分比是 DeepSeek 对给定选项的相对权重，未经校准，不是对方意图的客观概率。危险/紧张度是模型辅助提示，不能单独作为关系结论。只有经本机微信消息库核对的已选择聊天普通文字参与分析；图片、视频、链接等不进入模型。设置、启用名单与 API Key 不包含在发布包中。

## 发布包跨机器检查

发布包含 276 个文件；全新目录解压后，启动器和后台的隔离 `--self-test` 均返回 0。压缩包不含个人聊天选择、运行状态、数据库、图片或 API Key；原生启动器的导入依赖是 Windows 系统组件，没有直接引用本机 MinGW 运行库。此项只证明包自洽，不能证明其他电脑上的微信兼容。

跨机器限制来自代码中的精确主程序路径、微信文件版本、`Weixin.dll` 路径和固定二进制布局校验。必须是原生 x64 Windows、相同用户会话中已登录且可见的微信 4.1.13.65；安装到其他路径或微信更新后不能保证启动。第二台电脑仍需自行填写 DeepSeek API Key 并重新选择聊天；本次没有在第二台电脑做实测。
