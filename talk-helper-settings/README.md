# talk helper · 跨电脑便携版 v13r2.7

适用于已验证构建的微信 **4.1.13.65 / 4.1.15.13 x64**，允许微信安装在不同磁盘和目录。保留微信原界面，对方普通文字下方显示独立建议框，并为建议自动撑开原消息行。

## 在另一台电脑使用

发布包可解压到可写的普通文件夹，无需安装 Python 或编译器；请保留压缩包中的目录结构。程序从正在运行的微信进程读取实际安装路径，不再要求 `C:\Program Files\Tencent\Weixin`。启动器核对 `Weixin.exe` 的版本和已验证构建指纹，原生模块与后台也核对 `Weixin.dll` 的构建指纹，然后才启用针对该构建的内嵌消息排版。支持**这两个已验证构建的不同安装路径和电脑**；其他微信版本或同版本不同二进制构建会拒绝加载，不会冒险套用旧内存布局。尚未在第二台电脑上现场测试。

满足上述条件时，先在那台电脑自行登录微信并保持主窗口打开，再运行解压目录中的 `TalkHelper-Native-v13.exe`。右键微信输入栏的 talk helper 入口打开设置，填写该电脑自己的 DeepSeek API Key，并选择要启用的聊天。API Key 存在该 Windows 用户的凭据管理器里，启用名单和聊天档案也只在本机保存；发布包不含这些个人设置。以后每次完全退出并重开微信，都需再次运行启动器。

## 启用和选择聊天

从旧版更新到本版，先保留未发送草稿并**完全退出微信**，再替换原生模块和后台文件夹，重开微信后运行 `TalkHelper-Native-v13.exe`。新版更新了进程内 DLL，单独关闭 talk helper 不能卸载旧 DLL。同目录的 DLL、config.json 和完整的 `TalkHelperNativeWorker-v13r2` 文件夹均需保留。

点击输入工具栏的 talk helper 入口，搜索并勾选联系人或群聊；右键也可以启用/停用当前聊天。默认不选择聊天，已有本机启用名单随本次更新保留。发布包不包含个人启用名单。

本版补充联系人聊天的标题读取，名称核对改用精确查询，支持短昵称、特殊符号和备注名称。同名联系人仅在其中一个对象拥有有效聊天会话时使用该会话；多个同名有效会话仍保持关闭。选择列表包含本机联系人及已有会话；最多显示 3000 条。列表中没有的联系人，先打开该聊天，再从右键启用当前聊天。

## 右键设置

右键输入工具栏入口或任一建议框，选择 **“设置…”**。设置页是微信进程内的窗口，运行期间不需要打开独立助手主程序。`TalkHelper-Settings-v13.exe` 也提供直接打开设置的快捷入口。

通用设置：助手显示名称、AI 模型名称、API Base URL、API Key。Base URL 保留 DeepSeek 官方直连限制，支持 `https://api.deepseek.com` 和 `/v1`，拒绝 OpenRouter、其他域名、代理及跨域重定向。误填官方完整 `/chat/completions` 地址会自动规范。

“连接与聊天”页：对象身份（可选择或自行填写）、回复风格、常用语、上下文条数 3～30、思考模式。勾选“只应用到当前聊天”后，这些设置只保存在当前账号的该联系人或群聊下；取消勾选则修改通用默认值。连接设置与助手名称始终共用。

“双方档案”页：你和对方各自的 MBTI 与 0～100 主观评分、你的优势和短板、对方代号、目前关系阶段。“经过与目标”页：相识方式、认识时长、最近三件关键事、联系和双方投入、当前目标以及你此刻最在意的点。这两页仅在当前聊天范围可编辑，所有项目均可留空。MBTI 用四个字母填写；评分仅表示你当下的主观看法，不表示人的价值或关系成功率。

档案由你手动填写并点击保存后，保存在本机配置文件的当前微信账号与当前聊天下；程序不会从聊天记录自动建立或更新档案。分析该聊天时，已填资料作为主观背景发送至 DeepSeek 官方接口，空白项不会发送。群聊中，只有对方代号与当前发言人完全相同时才应用对方专属资料；否则只提供你的资料及通用目标。发布包不包含任何个人档案。

点击 **“保存并应用”** 后设置立即生效，当前可见建议重新生成，旧设置的正在生成结果会被丢弃。常用语只在自然合适时作为风格参考。

API Key 输入框为空时保留现有密钥，不显示原密钥。新密钥存入当前 Windows 用户的凭据管理器；配置文件与发布包不保存明文密钥。已有 `DEEPSEEK_API_KEY` 继续作为兼容来源。

## 聊天时间

直接读取每条文字消息的微信 `create_time`，不识别截图，也不把图片中嵌入的钟表时间当成发送时间。原微信的日期和时间分隔栏由微信继续显示，分隔栏本身不会生成建议。

气泡标题显示发送时间；详情显示完整发送日期、时区、与上一条参与分析的普通文字间隔和本次生成参考时间。图片、视频等仍不进入模型，因此这里的间隔是普通文字之间的间隔。

起草和判断都携带独立时间元数据：按发送日期理解“今天、昨天、明天”，参考跨日和较长间隔，区分历史消息与刚收到的消息。距分析时超过 6 小时标记为历史参考，不默认对方仍在等待或旧截止时间尚未到；单凭间隔不推断情绪、是否一直未回复或旧话题已结束。时间缺失不推测，未来时间提示核对设备时钟。

建议缓存保留本次生成时的时间参考；时间流逝和滚动不自动重新生成，右键“重新生成这条建议”会使用新的分析时间。

## 建议方式

每条对方普通文字下方显示独立灰色分析卡片。卡片按当前消息与上下文选择一个值得判断的问题，显示两项模型参考权重；再列出最可能的两种对话用途与“其他”、紧张度及一条当前动作。分析完成后自动加高原消息行，为多行卡片留出空间；滚动时卡片继续贴随该消息。点击“详情”可看完整理由、行动步骤和可复制的候选回复。

百分比是模型对候选解释的相对权重，**不是对方真实心理或行为的准确概率**。证据不足时应以原话和后续反馈为准。明确要求停止联系的文字直接显示停止建议，不编造百分比。

根据狗头军师 skill 的沟通原则，优先看最新原话、已知事实和未确认信息，再给当前最有用的一个动作。普通问事直接回应或核实；朋友和群聊不强行解读为暧昧或情绪测试。确有双方愿意的约会目标时，可给具体、低压力、允许拒绝的主动提议。

本版不再把“顺着对方说”当作默认建议。遇到明确问题先回答或查证；要求无法兑现或不合理时可以说明限制、提出边界；没有证据时不把施压一概解释为玩笑，也不为了显得有主见而抬杠。首条建议必须给出针对这句话的具体动作，“顺着聊”“接住情绪”等空泛首句会被退回重写。

每条建议首项是首选做法，下一项说明后续该观察的实际反馈或停止条件；有真实权衡时才给替代做法。候选回复贴近本人已有口吻，避免凭短回复、表情或一次延迟推断对方心理，也不提供贬低、失联测试、嫉妒或逼迫话术。模型判断仍可能出错，请结合实际关系和现场反馈决定是否使用。

单聊中收到明确的“不要再联系我”等要求时，程序直接给出停止联系建议，不调用模型，也不提供可复制的回复。被引用、混合描述和群聊中的相似文字不能据此认定对方在要求你停止联系。

## 气泡与滚动

建议与已核对的原生消息对象绑定。微信处理滚轮、拖动滚动条、布局和绘制消息后，直接按原消息行的当前位置更新气泡；另有约 16 毫秒的界面刷新作为补偿。滚动定位不等待文字扫描或 DeepSeek。

滚出聊天区域时裁剪气泡，滚回来恢复同一建议与已选回复；临时文字扫描失败、部分可见或旧位置超时不会撤销已绑定的建议。气泡上的滚轮转交给微信聊天列表。新文字仍须首次核对后才生成；不承诺系统卡顿时绝对零延迟。

缓存保留在本次运行的内存中，不写入聊天内容文件。切换聊天、停用、删除原消息、退出功能或后台服务结束时会解除对应绑定；退出微信后需要重新启用。

## 消息和原功能

只分析已启用聊天中能与本机消息库核对的对方普通文字。自己发送的文字不显示建议；发件人优先按所在消息库的实际账号标识核对。图片、视频、语音、表情、链接、文件、小程序及带网址的文字不进入分析。原消息、头像、昵称、右上角按钮和头像资料卡由微信原控件处理。

不使用 OCR。只有选中聊天的文字会发送到 DeepSeek 官方接口。点击详情可查看具体行动、回复候选和注意事项；复制不会自动发送。

## 关闭与恢复

运行 `TalkHelper-Stop-v13r2.exe` 或右键关闭功能，会移除建议并恢复原消息行高。没有修改微信安装文件。DLL 留在本次微信进程中，退出微信后消失；微信重启后需重新启用。

如果提示“控件证明消息未通过”，旧控件可能已不响应；退出并重开微信后重新启用。重启前请保留未发送草稿。本程序不绕过这条校验。

## 验证和范围

53 项后台 Python 测试与 114 项分析链测试通过，覆盖消息归属、纯文字过滤、独立建议、联系人标题读取、重复文字定位、末条消息原生尺寸核对、按聊天和账号保存、关系档案隔离、群成员身份核对、连接限制、明确停止联系、空泛建议重写、模型权重校验、卡片格式及不同路径的构建指纹校验。原生隔离测试通过，含新卡片在顶部、底部及高 DPI 时的裁剪与定位。

仍限定于上述两个经过指纹核对的微信构建。引用消息、超长消息没有完整撑开支持；消息须能在最近 150 条本机记录中唯一核对。首次遇到部分露出的消息待完整可见后核对；已核对的消息支持部分可见时继续显示并裁剪气泡。聊天数据的临时解密快照在正常退出时清理，异常终止可能留下临时文件。

保留上一版的联系人启用和设置。v13r2.5 的灰色分析卡片已在真实微信中验证，记录见 `VALIDATION-v13r2.5.md`。本版改动微信主程序、进程内模块和后台的构建校验路径；具体验证见 `VALIDATION.md`。
