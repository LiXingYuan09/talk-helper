# v13r2.7 双版本便携包验证

适用范围：腾讯签名的微信 4.1.13.65 和 4.1.15.13 x64 的指定二进制构建。实际安装目录可变；未知构建拒绝加载。兼容其它微信版本或未经测试的同版本构建不在本次结论内。

## 4.1.15.13 本机现场

- 从腾讯官方安装包提取并核对 4.1.13.65 的原始 `Weixin.dll`，与此前适配指纹一致；对照本机 4.1.15.13 文件重新定位原生消息列表、数据模型、行高计算、布局刷新和辅助功能初始化。
- 启用前只读检查当前登录微信：聊天列表的 31 个消息项、9 个可见文字行、行边距与窗口坐标均能定位；22 个本地数据库的密钥校验通过。没有使用 OCR，也没有打印聊天内容。
- 新版已装入当前微信。启动器回报“微信原界面建议已启用”；后台记录显示当前聊天已选择、原生布局接受、消息行预留空间、独立气泡可见，DeepSeek 请求已有成功返回，没有后台异常。
- 界面现场检查可见两条不同的对方文字消息，各自下方有独立建议框；上下滚动时建议框跟随对应原消息，头像、时间分隔与原聊天工具栏仍由微信显示。

## 构建和便携检查

- 原生模块、启动器、卸载器和设置入口编译成功；原生隔离自检通过。
- 后台 53 项单元测试和打包后台自检通过。C++ 指纹检查对 4.1.13.65 与 4.1.15.13 的 EXE/DLL 配对均通过。
- 发布包包含后台运行时，无需目标电脑安装 Python 或编译器；不包含 API Key、聊天启用名单、关系档案或聊天数据。277 个包内文件已在名称含空格的全新目录中解压，原生启动器和后台自检均返回 0，解压后的原生 DLL 与构建产物指纹一致。

## 未覆盖

- 尚未在第二台电脑实际运行；不同安装目录的指纹验证和免固定路径实现不能代替异机端到端测试。
- 4.1.13.65 在更新前曾现场运行；本次双版本构建保留其原布局参数，但本机微信已经升级，无法同时重新做旧版现场验证。
- 客户端再次自动更新后，必须先验证新版本布局；程序会在未知构建上拒绝加载。
